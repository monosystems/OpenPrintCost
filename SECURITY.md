# Security Policy

## Supported versions

Only the latest release published under
[GitHub Releases](https://github.com/monosystems/OpenPrintCost/releases)
receives security fixes. Older versions are not maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use **GitHub Security Advisories** (Report a vulnerability) on this
repository so details stay private until a fix is released.

Include if possible:

- Affected version and install type (deb / AppImage / msi / dmg / source)
- Steps to reproduce or proof of concept
- Expected impact (e.g. arbitrary file write, data loss, RCE)

We will confirm receipt, assess the report, and publish a fixed release with
credit to the reporter (unless anonymity is requested).
